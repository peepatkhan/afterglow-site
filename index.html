Your code stays put.

Afterglow reads the log files your agents already write on disk. That's all it does with them.

  • Reads ~/.claude/projects and ~/.codex/sessions locally
  • Nothing leaves your Mac: no account, no analytics, no network calls
  • Optional privacy mode hides commands, file names and replies on screen

Questions

Which agents does it support?

Claude Code and the Codex CLI today. Tell us what you use when you join the beta, as more are on the way.

Is it a screen saver?

It works like one, but it's a regular full-screen window shown after you've been idle. On first launch Afterglow helps you turn off the macOS screen saver so it doesn't cover the view.

How does it know an agent needs me?

It follows each session's log as it's written. When an agent ends its turn, it's your turn. When a tool call sits pending for a while, it's probably asking for permission.

What does it cost?

The beta is free. A paid version with extra features may come later, and beta testers will hear about it first.

What do I need?

A Mac on macOS 14 Sonoma or later, plus Claude Code or Codex.

Does it slow my Mac down?

It's designed not to. It reads only the new lines of each log every couple of seconds, and the full-screen view runs only while you're away.
